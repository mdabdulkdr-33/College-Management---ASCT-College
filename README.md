# 🎓 All Saints' College of Technology (ASCT) Portal

A lightweight, modern, and fully interactive **College Web Portal** frontend designed for managing academic departments, showcasing faculty profiles, and facilitating seamless student registrations. 

Built using pure web fundamentals (**HTML5, CSS3, and Vanilla JavaScript**), this project provides a clean user interface coupled with smart client-side data management.

## 🚀 Features

* Dynamic Faculty Directory: Fetches and displays faculty details dynamically using JavaScript arrays with integrated high-quality placeholder profile portraits.
* Smart Filter & Search: Instant text-based searching for faculty and interactive filtering options for academic departments (Engineering vs. Management).
* Robust Student Registration: A validation-secured form that processes enrollment applications and stores data securely using browser `localStorage`.
* Dynamic Success State: Redirects registered users to a customized confirmation screen with a clean vector tick-mark notification layout.
* Offline Receipt Generator: Generates and triggers instant `.txt` receipt downloads for both student registration forms and department brochures completely client-side.
* Fully Responsive UI: Engineered with advanced CSS Media Queries ensuring seamless usability across mobile devices, tablets, and desktop displays.
